The Mechanics of Migrating js to ts gradually

Enable allowJs, rename files to .ts one folder at a time. That is the core of it, and the steps below turn the idea into muscle memory:

  1. Review the setup with the team and record one owner responsible for it.
  2. Document the rollback path before you need it, not during an incident.
  3. Write the chosen setup down in the repository so the decision survives the next refactor.
  4. Pick the smallest meaningful change you can ship and measure — momentum matters more than scope.
  5. Add a check to CI so regressions in migrating js to ts gradually fail loudly instead of silently.
