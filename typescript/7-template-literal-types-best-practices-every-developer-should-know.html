What Is Template literal types?

Template literal types, in one sentence: string types built from patterns. In practice that means the details are worth getting right once, because everything downstream inherits the decision. Teams that invest here early spend measurably less time firefighting later in the project.

The mental model is simple: one clear definition, one clear workflow, and configuration that matches reality. Most confusion around template literal types comes from mixing those layers — mixing definitions from different eras, or configs copied from projects with different needs.
