Troubleshooting Migrating utilities from csharp

When things break, symptoms cluster into a handful of patterns. Match yours here and jump straight to the fix:

  • It fails intermittently under load — look for shared state and timing assumptions that only break when things overlap
  • It works on one machine and fails on another — diff the versions and configuration first — environment drift explains most of these bugs
  • Errors mention a file or component you never touched — trace the first error in the log, not the last one — the real cause is almost always earlier
