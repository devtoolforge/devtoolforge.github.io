Performance Considerations

Measure first. Capture baseline numbers for the scenario you care about before touching anything, because intuition about hot paths is famously wrong. For collection expressions, that usually means timing the end-to-end operation, not the method you suspect, and recording memory alongside time. A ten-minute baseline turns a week of speculation into an afternoon of targeted work.

Watch the tails, not the averages. Median numbers hide the p95 and p99 latencies that users actually feel. For collection expressions workloads, repeated runs under realistic data sizes reveal the variance that a single clean run misses. Set a budget for the worst case, not the best case, and design for it.
