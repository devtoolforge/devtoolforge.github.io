What Is Init-only setters?

Init-only setters, in one sentence: properties that can be set only during object initialization. In practice that means the details are worth getting right once, because everything downstream inherits the decision. Everything below assumes the current 2026 toolchain, but the reasoning generalizes to older versions too.

The mental model is simple: one clear definition, one clear workflow, and configuration that matches reality.
