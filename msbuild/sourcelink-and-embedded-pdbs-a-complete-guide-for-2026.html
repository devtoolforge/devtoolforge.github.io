What Is Sourcelink and embedded pdbs?

Troubleshooting Sourcelink and embedded pdbs

When things break, symptoms cluster into a handful of patterns. Match yours here and jump straight to the fix:

  • It fails intermittently under load — look for shared state and timing assumptions that only break when things overlap
  • It works on one machine and fails on another — diff the versions and configuration first — environment drift explains most of these bugs
  • It fails only in CI but passes locally — compare build modes and clean versus incremental state; CI reveals stale-output bugs instantly

If none of these match, capture a full log before changing anything. For sourcelink and embedded pdbs that log almost always names the failing layer, and the fix becomes obvious instead of guessed.

Quick Example

Here is a compact, real-world xml example you can adapt directly. It shows the configuration style we recommend for sourcelink and embedded pdbs: explicit, commented where it matters, and free of magic.

<Target Name="StampBuild" BeforeTargets="Build">
  <PropertyGroup>
    <BuildStamp>$([System.DateTime]::Now.ToString(yyyyMMddHHmmss))</BuildStamp>
  </PropertyGroup>
  <WriteLinesToFile File="$(OutputPath)stamp.txt" Lines="Built at $(BuildStamp)" Overwrite="true" />
</Target>

Copy it, run it once, then trim it to what your project actually needs. The worst version of any snippet is the one nobody on the team fully understands.
