Visual Studio October 23, 2026

The fastest developers are not typing faster; they are touching the mouse less. Visual Studio 2026 continues to pile on keyboard-first features, from numbered tab shortcuts to Copilot chat bindings, yet most developers still use a fraction of the shortcuts available.

Here are fifty shortcuts that genuinely change how fast you move through Visual Studio, organized by task so you can learn them in themed batches. Ten minutes of practice per section compounds into hours saved every week.

Navigation: Getting Anywhere in Seconds

  • Ctrl+T: Go to All (files, symbols, members, types)
  • Ctrl+, : Navigate To search
  • F12: Go to definition; Ctrl+F12: go to implementation
  • Alt+F12: Peek definition without leaving the file
  • Ctrl+- / Ctrl+Shift+- : navigate back/forward
  • Ctrl+Numpad 1-9: activate visible document tab (new in 2026)
  • Ctrl+Tab: IDE navigator with previews
  • Shift+Esc: close the current tool window

Batch-learn navigation first: the Go To family replaces most mouse trips to Solution Explorer within a day of practice.

Editing and Refactoring

  • Ctrl+D: duplicate line; Shift+Delete: cut line
  • Alt+Up/Down: move line(s); Shift+Alt+.: smart expand selection
  • Ctrl+R,R: rename symbol; Ctrl+R,M: extract method
  • Ctrl+.: quick actions and refactorings lightbulb
  • Ctrl+K,C / Ctrl+K,U: comment/uncomment selection
  • Ctrl+K,D: format document; Ctrl+K,F: format selection
  • Ctrl+Shift+L: select all occurrences at once

Debugging Without the Mouse

  • F5: start; Ctrl+F5: start without debugging
  • F9: toggle breakpoint; Ctrl+F9: enable/disable
  • F10: step over; F11: step into; Shift+F11: step out
  • Ctrl+F10: run to cursor
  • Shift+F9: quick watch; Ctrl+Alt+Q: immediate window
  • Ctrl+Shift+F5: restart; Shift+F5: stop

Search, Build, and Windows

  • Ctrl+Shift+F: find in files; Ctrl+H: replace
  • Ctrl+B / Ctrl+Shift+B: build project / solution
  • Ctrl+`: open the integrated terminal
  • Ctrl+W,W: window search; Alt+6: output window
  • Ctrl+Q: search options and commands (quick launch)

Making Shortcuts Stick

Learn five per day inside the editor: press Ctrl+Q, search the command, note its binding, and force yourself to use it ten times. Print Microsoft's per-profile cheat sheet and tape the debug section next to your monitor; within two weeks the fifty shortcuts above become muscle memory and the mouse becomes optional.

Frequently Asked Questions

Do these shortcuts work in Visual Studio 2022?

Most do. The numbered tab shortcuts (Ctrl+Numpad) and a few others are new to Visual Studio 2026, and everything else works in 2022 with the default profile.

My shortcuts differ. Why?

Keyboard mapping schemes (General, C#, Visual Basic, Emacs) rebind many keys. Check Tools > Options > Environment > Keyboard to see or change the current scheme.

Can I create my own shortcuts?

Yes, in Tools > Options > Keyboard: search the command, assign a binding, and resolve conflicts. Exported settings carry them to other machines.

What is the fastest way to discover shortcuts?

Watch the labels: menu items display their bindings, and the Command window echoes each command as you invoke it with the mouse.
