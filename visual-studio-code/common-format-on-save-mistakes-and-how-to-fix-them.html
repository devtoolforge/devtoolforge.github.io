What Is Format on save?

Format on save, in one sentence: automatic formatting when a file is saved. In practice that means the details are worth getting right once, because everything downstream inherits the decision. Small teams benefit as much as large ones, often faster because they can change habits quickly.

The mental model is simple: one clear definition, one clear workflow, and configuration that matches reality.
