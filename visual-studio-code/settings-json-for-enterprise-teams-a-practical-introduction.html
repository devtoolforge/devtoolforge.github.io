What Is Settings.json?

Settings.json, in one sentence: the JSON file that controls editor and extension behavior. In practice that means the details are worth getting right once, because everything downstream inherits the decision. It is one of the few practices that pays for itself within the first week of consistent use.

The mental model is simple: one clear definition, one clear workflow, and configuration that matches reality. Most confusion around settings.json comes from mixing those layers — mixing definitions from different eras, or configs copied from projects with different needs. Keep them separate and the rest of this guide follows naturally.

Quick Example

Here is a compact, real-world json example you can adapt directly. It shows the configuration style we recommend for settings.json: explicit, commented where it matters, and free of magic.

  "configurations": [
