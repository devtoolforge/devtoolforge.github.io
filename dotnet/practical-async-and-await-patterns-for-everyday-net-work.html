Performance Considerations

Remove work before making work faster. The cheapest optimization for async and await patterns is usually doing less: fewer allocations, fewer passes, fewer round trips. Profile to find work that can be skipped entirely under normal conditions. Only then reach for caching, and only with an explicit invalidation plan.
